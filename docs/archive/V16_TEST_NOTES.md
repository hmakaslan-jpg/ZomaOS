# ZomaOS V16 — six selectable themes (test source)

Contains 3 original themes and 3 new mockup-based scenes, with functional dock hit targets, settings hotspot and clock/gauge selection. The new scene artwork was generated as static mockups, so its pictured vehicle may not exactly match the real Geely Emgrand X7 2019; source artwork is not a verified vehicle photo. Status indicators and any voltage figures in static artwork are illustrative, not telemetry. New scene overlays mask the principal static time, clock, media and dock areas.

This source has NOT been compiled by Gradle or runtime-tested on the vehicle. Build in GitHub Actions, then verify layout, touch, Android compatibility and USB resume before relying on it. Preserve the known-working APK.
