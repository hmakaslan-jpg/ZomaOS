# ZomaOS V12.5 — verification and limitations

- Four theme resources are derived from the user-approved 2x2 concept collage, resized to 800x480. No climate bar.
- The original V12.4 music/USB resume logic is preserved.
- Clock/date, analog hands, track metadata, seek progress and source text are redrawn at runtime; mock weather/USB capacity are not represented as live data.
- Dock actions: USB Music, Radio FM, Android Auto, OBD, File Browser. Long press changes program.
- Sidebar actions and Wi-Fi/Bluetooth settings mapped to the new layout.
- Radio frequency integration remains unavailable. Climate controls deliberately removed.
- Caution: The approved concept is a raster visual reference; some noninteractive decorative icons and sample album art remain part of the background.
- Static checks do not substitute for Gradle build or in-car touchscreen tests.
