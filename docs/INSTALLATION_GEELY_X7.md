# ZomaOS Free — installation guide (tested unit)

**Compatibility:** Verified only on the developer's original Geely X7 2019 Android head unit. Other hardware/firmware may differ. This guide is based on the developer's own successful installation procedure, not a universal bypass.

## English
1. Format a USB flash drive as **FAT32** and copy the ZomaOS APK to it.
2. On the original head unit, change the date to **1 January 2000**.
3. Open the unit's screen displaying the **barcode**.
4. Tap the barcode **seven times** to reveal the hidden File Manager on the tested firmware.
5. Open the USB drive in File Manager, select the APK and install it.
6. Confirm the launcher opens and test buttons and themes. If installation is blocked, do not bypass security warnings; report the firmware version.

## العربية
1. فرمت فلاشة USB بنظام **FAT32** وانسخ عليها ملف ZomaOS APK.
2. غيّر تاريخ الشاشة الأصلية إلى **1/1/2000**.
3. افتح صفحة **الباركود** في إعدادات الشاشة.
4. اضغط على الباركود **7 مرات** لفتح مدير الملفات المخفي (على إصدار الشاشة المُجرّب).
5. افتح الفلاشة من مدير الملفات، واختار ملف APK وثبّته.
6. جرّب فتح اللانشر والأزرار والثيمات. لو التثبيت اتمنع، ما تتجاوزش تحذيرات الأمان؛ بلغنا بإصدار السوفت.

## Русский
1. Отформатируйте USB-накопитель в **FAT32** и скопируйте APK ZomaOS.
2. Установите дату штатного головного устройства на **01.01.2000**.
3. Откройте экран со **штрихкодом**.
4. Нажмите на штрихкод **7 раз**, чтобы открыть скрытый файловый менеджер (на проверенной прошивке).
5. Откройте USB-накопитель, выберите APK и установите его.
6. Проверьте работу лаунчера, кнопок и тем. Если установка блокируется, не обходите предупреждения безопасности; сообщите версию прошивки.

**Before public release:** use a properly release-signed APK, publish checksums and clear version information, and test the download link. Do not distribute a debug APK as the official public release.
