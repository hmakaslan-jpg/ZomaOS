# ZomaOS Global Launch Kit (Draft — not yet posted)

## English announcement

**ZomaOS Free — a new launcher project for legacy Geely X7 head units**

Hi Geely X7 owners! I'm building ZomaOS, a lightweight launcher for compatible older Android head units. The current free preview has Carbon, Electric and Day themes, a clock, USB music controls, and shortcuts to common head-unit apps.

It has been tested on one original 2019 Geely X7 unit (800×480, Android 4.x). Other hardware and firmware are not yet verified. I'm looking for volunteer testers who can share their exact device specs and feedback. Please install only when parked and make sure you can restore your original launcher.

Project: https://github.com/hmakaslan-jpg/ZomaOS

This is an independent community project, not an official Geely product. Please check community rules before posting.

## Russian announcement

**ZomaOS Free — лаунчер для старых мультимедийных систем Geely X7**

Разрабатываю ZomaOS — лёгкий лаунчер для совместимых Android-магнитол Geely X7. В текущей бесплатной тестовой версии есть три темы (Carbon, Electric, Day), часы, управление USB-музыкой и ярлыки приложений.

Пока проект проверен только на одном штатном устройстве Geely X7 2019 года с экраном 800×480 и Android 4.x. Совместимость с другими устройствами не подтверждена. Ищу добровольных тестировщиков: укажите модель магнитолы, прошивку, версию Android и результаты проверки. Устанавливайте приложение только на припаркованном автомобиле и убедитесь, что можете восстановить штатный лаунчер.

Проект: https://github.com/hmakaslan-jpg/ZomaOS

Независимый проект сообщества, не связанный с Geely.
